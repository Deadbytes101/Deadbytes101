# DEADBYTE

`C17` · `Rust` · `x86 / x86-64 assembly` · `reverse engineering`

I work on programming languages, native tools, filesystems, graphics, and old hardware. I prefer reading the bytes to guessing what the machine is doing.

**MOST PEOPLE WRITE CODE TO SOLVE PROBLEMS.**  
**I WRITE CODE BECAUSE I DO NOT WANT TO DEPEND ON ANYONE ELSE'S SOFTWARE.**

## Selected work

| Project | What it does |
| --- | --- |
| [DBYTE](https://github.com/Deadbytes101/DBYTE) | Systems-oriented language, compiler, VM, and bare-metal experiments. |
| [DEADBYTE MCP](https://www.npmjs.com/package/deadbyte-mcp) | MCP tooling for machine operations, with explicit authority and verifiable execution. |
| [DBYTEPAD](https://github.com/Deadbytes101/DBYTEPAD) | Small native Win32 text editor written in C. |
| [DEADGL](https://github.com/Deadbytes101/DEADGL) | C99 software renderer. Command stream in, pixels and proof hashes out. |
| [DEADFLASH](https://github.com/Deadbytes101/DEADFLASH) | Native disk-image writing and readback verification. |
| [SHINESEA](https://github.com/Deadbytes101/SHINESEA) | Rust filesystem image core, integrity checks, and recovery experiments. |
| [A780L3B BIOS research](https://github.com/Deadbytes101/dbyte-a780l3b-bios-research) | ROM analysis and firmware experiments on a BIOSTAR board. |
